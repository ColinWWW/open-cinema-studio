# Workflows

## stage1_layout_api.json (what the server runs)

Our own stage-1 Layout-to-Render graph, **ComfyUI core nodes only** (LTX-2.5 and the IC-LoRA guide
nodes are native in ComfyUI), so no custom nodes and nothing copied from Lightricks' LTX-licensed
workflow. It's generated by `server/workflow.py` (`python -m server.workflow`); a unit test fails if
the file and the generator drift apart. The wiring follows ComfyUI's MIT templates (LTX-2.5 I2V and
LTX-2.3 IC-LoRA) plus the model card's settings: LoRA 1.0, CFG 1, euler_ancestral, seed 42, 8
distilled steps; the look still replaces frame 0 and the layout clip is the IC-LoRA guide.

Checked on an A40 (Oct 21, ComfyUI 0.42.1): the plaza example renders like the go/no-go run of the
official workflow (`examples/stage1_core_plaza_a40.mp4` vs `gonogo_stage1_plaza_a40.mp4`, contact
sheet in `examples/stage1_core_plaza_frames.png`), with an audio track as a bonus. ~95 s warm.
The official workflow below stays as a fallback.

## look_still_depth_api.json (the look still)

Frame 0's depth map (exported by `web/` with the playblast, near = white) + the prompt → a finished
first frame that matches the layout box for box. **Z-Image-Turbo** with alibaba-pai's **Fun ControlNet
Union 2.1** (2602, 8-step) in depth mode, both Apache-2.0, through ComfyUI core nodes only
(`ModelPatchLoader` + `QwenImageDiffsynthControlnet`). Also generated by `server/workflow.py`. Wiring
and settings follow ComfyUI's MIT template `image_z_image_turbo_fun_union_controlnet`: AuraFlow shift
3, 8 steps, CFG 1, res_multistep/simple, zeroed negative, ControlNet strength 1.0 (the model card's range
is 0.65–1.0). It samples at ~1 MP with the clip's shape (1328×800 for 960×576) and scales the result to
the playblast's exact size.

Checked on an A40 (Oct 21, ComfyUI 0.42.1, no custom nodes): the plaza depth map gives a photoreal still
with the tower, lamp post, crates and kiosk where the boxes are (`examples/look_gen_plaza_a40.png`,
51.8 s cold incl. model load), and the stage-1 render from it holds that look while following the layout
(`examples/stage1_genlook_plaza_a40.mp4`, 166 s; contact sheet `examples/stage1_genlook_plaza_frames.png`).
Box heights are followed more loosely than positions (the big front crate came out as two lower crates).

## The official workflow (fallback, not in the repo)

The starting point is Lightricks' official `LTX-2.5_ICLoRA_Layout_To_Render_Two_Stage_Distilled.json`.
`scripts/setup_pod.sh` downloads it into ComfyUI's workflow browser. It isn't copied here, because it
ships under the LTX license.

Once it runs on the pod (int8 loaders, stage 1 only at first):

1. Title the nodes the server needs to set (right-click > Title):
   - layout video loader → `CS_LAYOUT_VIDEO`
   - first-frame image loader → `CS_FIRST_FRAME`
   - positive prompt → `CS_PROMPT`
   - node holding the seed → `CS_SEED`
   - final video save → `CS_OUTPUT`
2. **Workflow > Export (API)** → `workflows/cinema_studio_api.json` (our modified version, the one the server runs).
3. Run `python scripts/check_open_weights.py workflows/cinema_studio_api.json` before committing.

`server/comfy_client.py` patches inputs by these titles, so node ids never matter.
